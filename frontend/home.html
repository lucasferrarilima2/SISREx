Sistema Inteligente de Controle e Monitoramento de Acesso

Solução moderna, segura e auditável para o controle de entrada e saída de militares e visitantes, empregando reconhecimento facial para garantir agilidade, precisão e segurança no perímetro da Organização Militar.

Reconhecimento facial Registro automático Auditoria completa

Contexto e finalidade

Problema identificado

  • Falta de precisão no registro de entrada e saída de militares.
  • Processos manuais sujeitos a erro.
  • Vulnerabilidade à entrada de pessoas não autorizadas.
  • Dificuldade de rastreamento em tempo real.
  • Ausência de dados históricos organizados.

Objetivo principal

Implementar um sistema inteligente e seguro que automatize o controle de acesso de militares e visitantes na Organização Militar.

  • Registrar automaticamente horários de entrada e saída.
  • Garantir que apenas pessoas autorizadas tenham acesso.
  • Gerar relatórios para uso administrativo e disciplinar.

Funcionamento e arquitetura

Como o sistema funciona

  • A identificação pessoal é realizada por reconhecimento facial.
  • O acesso pode ser liberado por catracas integradas a um controlador de acesso IDFace.
  • Ao fazer o reconhecimento, o sistema verifica o cadastro no banco de dados, libera ou nega o acesso e registra nome, nome de guerra, posto e horário.

Tecnologias utilizadas

  • Frontend: HTML5, CSS3 e JavaScript (face-api.js) para uma interface interativa e responsiva.
  • Backend: Node.js com Express.js para uma API robusta e segura.
  • Banco de dados: arquivos JSON para armazenamento de logs e perfis, com controle de permissões.
  • Operação offline: validação local com backup para casos de queda de rede.

Resultados esperados

Benefícios para a Organização

  • Maior controle e segurança no perímetro.
  • Redução de falhas humanas.
  • Agilidade na liberação de acessos.
  • Histórico organizado para fins administrativos e disciplinares.

Segurança e confiabilidade

  • O reconhecimento facial garante que o acesso seja pessoal e intransferível.
  • Auditoria completa de todos os registros de acesso.
  • Backup automático dos dados para garantir a integridade das informações.
  • Capacidade de operação em modo offline temporário para emergências.
